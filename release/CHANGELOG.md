# Dubbo Invoke 更新日志

## v1.2.0 (2025-09-19) 🎉

### 🆕 新增功能

#### JSON结果展示增强
- **树形结构显示**：实现可折叠/展开的JSON树形展示，大型JSON数据更易查看
- **多功能工具栏**：在"调用结果"右侧新增6个实用工具图标
  - 🔄 压缩/美化切换：在压缩和格式化JSON之间切换
  - 📝 行号显示：显示/隐藏行号功能
  - 🗑️ 清空结果：一键清空结果区域
  - 💾 保存结果：将结果保存为JSON文件下载
  - 📋 复制结果：复制原始JSON数据（不含HTML标签）
  - 📂 全部展开/收缩：一键展开或收缩所有JSON节点
- **鼠标悬停提示**：每个工具图标都有功能说明提示

#### 用户体验优化
- **表达式格式默认**：将表达式格式设为默认选中项，更符合用户使用习惯
- **页面加载优化**：页面加载时自动切换到表达式格式界面

### 🔧 问题修复

#### 参数解析优化
- **复杂参数格式支持**：修复表达式模式下 `[],[],1` 等复杂参数格式解析问题
- **智能参数分割**：改进参数分割逻辑，正确处理多种参数组合
- **类型推断增强**：优化参数类型自动推断机制

#### 数据处理改进
- **复制功能修复**：修复复制功能会复制HTML标签的问题，现在只复制纯JSON数据
- **原始数据存储**：增加全局变量存储原始JSON数据，确保复制和保存的数据完整性

### 🎨 界面改进

#### 样式优化
- **工具栏样式**：新增美观的工具栏样式，图标间距合理
- **JSON树形样式**：添加专门的JSON树形展示CSS样式
- **行号样式**：为行号显示功能添加专门的样式支持

#### 交互体验
- **点击展开/收缩**：JSON树形节点支持点击展开和收缩
- **颜色区分**：不同数据类型使用不同颜色显示（对象、数组、字符串、数字等）
- **缩进显示**：清晰的层级缩进，便于理解JSON结构

### 📦 构建信息

#### 支持平台
- **Linux amd64** (10M)
- **macOS Intel** (10M) 
- **macOS Apple Silicon** (9.9M)
- **Windows amd64** (11M)

#### 构建特性
- 使用 `-ldflags "-s -w"` 优化，减小文件体积
- 跨平台兼容性测试通过
- 所有新功能在各平台均正常工作

## 技术细节

### 前端增强
- 新增 `renderJsonTree()` 函数实现JSON树形展示
- 新增多个工具函数：`toggleJsonFormat()`, `toggleLineNumbers()`, `clearResult()`, `saveResult()`, `expandAllNodes()`, `collapseAllNodes()`
- 优化参数解析逻辑，支持更复杂的参数格式

### 后端优化
- 改进 `processParametersWithBigIntSupport()` 函数
- 优化参数类型推断和转换逻辑
- 增强错误处理和日志记录

### 样式系统
- 新增 `.json-tree-*` 系列CSS类
- 新增 `.result-toolbar` 工具栏样式
- 新增 `.line-numbers` 行号显示样式
- 优化响应式设计，支持不同屏幕尺寸
