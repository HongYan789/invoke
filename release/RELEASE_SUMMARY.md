# Dubbo Invoke v1.2.0 发布摘要

## 📦 发布信息

- **版本号**: v1.2.0
- **发布日期**: 2025-09-19
- **发布类型**: 功能增强版本
- **兼容性**: 向后兼容

## 🎯 核心亮点

### 🆕 JSON树形展示系统
全新设计的JSON结果展示系统，让复杂数据结构一目了然：
- **可折叠树形结构**：点击展开/收缩任意节点
- **智能颜色编码**：不同数据类型使用不同颜色
- **层级缩进显示**：清晰的视觉层次结构

### 🛠️ 多功能工具栏
在调用结果区域新增6个实用工具：
- 🔄 **格式切换**：压缩 ↔ 美化显示
- 📝 **行号控制**：显示/隐藏行号
- 🗑️ **快速清空**：一键清空结果
- 💾 **文件保存**：下载JSON文件
- 📋 **智能复制**：复制纯JSON数据
- 📂 **批量操作**：全部展开/收缩

### 🎨 用户体验优化
- **表达式格式优先**：默认使用更直观的调用格式
- **智能参数解析**：支持复杂参数格式如 `[],[],1`
- **鼠标悬停提示**：每个功能都有详细说明
